# Synthetic Data

Reference copy of the certificate inventory used for the PoC.

## certificate_inventory.csv

20 synthetic certificate records generated by
`generate_dummy_certificates.py`.

**Coverage:**
- 8 fictional Mississippi agency names
- 5 certificate issuers (GlobalSign, DigiCert, Let's Encrypt,
  Amazon Trust Services, Mississippi ITS Root CA)
- 3 environments (production, staging, dev)
- All lifecycle states represented: active, expiring_soon,
  critical, expired, pending_deployment

**Key columns:**
`certificate_id`, `domain_name`, `agency_name`, `issuer`,
`certificate_type`, `environment`, `expiration_date`,
`days_to_expiry`, `renewal_threshold_days`, `status`,
`auto_renew_enabled`, `csr_required`, `deployment_status`

**To regenerate:**
```bash
python generate_dummy_certificates.py --count 20
```

## Important: two copies exist

| Path | Purpose |
|------|---------|
| `data/synthetic/certificate_inventory.csv` | Documentation reference (this file) |
| `generated_certificates/certificate_inventory.csv` | **Live runtime copy** — loaded by `api_bridge.py` at startup |

Do not remove `generated_certificates/certificate_inventory.csv`.
The Flask API reads from that path. This `data/synthetic/` copy
is for documentation and repository clarity only.

## What is NOT in this repository

- Real SSL/TLS certificates from any Mississippi agency
- Private keys (gitignored — never committed)
- CSR files (generated at runtime — gitignored)
- Real agency operational data or PII
